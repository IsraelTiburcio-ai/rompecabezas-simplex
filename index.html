    Mapa de equivalencias

    1. 01
      Cambiar max ↔ min

      Se invierte el signo de z y de toda la función objetivo.

      max z = cx ⇔ min z = −cx
      p. 6
    2. 02
      Negar una desigualdad

      Al multiplicar por −1, se invierte el sentido.

      Ax ≤ b ⇔ −Ax ≥ −b
      p. 6
    3. 03
      Descomponer una igualdad

      Es la intersección de dos desigualdades opuestas.

      Ax = b ⇔ Ax ≤ b y Ax ≥ b
      p. 6
    4. 04
      Holgura y exceso

      Para ≤ se suma holgura; para ≥ se resta exceso. Ambas variables son no negativas.

      Ax + y = b · Ax − w = b
      pp. 6–7
    5. 05
      Variable no restringida

      Se representa como diferencia de dos variables no negativas.

      x₁ = x₃ − x₄, con x₃, x₄ ≥ 0
      p. 7

    Fuente: Gimnasio 3. Método Simplex, sección 3.2 «Equivalencias», pp. 6–8.
